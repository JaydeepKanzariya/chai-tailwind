Under The Hood

How ChaiTailwind Works

Four deterministic steps from utility class names to native inline styles.

1

Write Classes

Author standard HTML with expressive chai-* utility classes and drop in one script tag.

2

Scan DOM

On load, querySelectorAll finds every [class*="chai-"] element in a single pass.

3

Parse & Cache

Longest-prefix registry lookup resolves spacing, palette colors, fractions, and [...] values with Map caching.

4

Inline Styles

Applies element.style in class order, removes processed chai-* tokens, and preserves custom classes.

1. Spacing & Sizing

p, m, gap, w, h

Plain numbers map to px. Supports auto, full, fractions (1/2), negative margins (chai--m-8), and arbitrary brackets.

chai-w-1/2 chai-p-8
chai-w-3/4 chai-px-16 chai-py-8
chai-w-4/5 chai-mx-auto

2. Colors

bg, text, border

Use built-in Chai palette tokens, any CSS named color (validated via CSS.supports), or arbitrary hex/rgb values.

bg-chai-500
text-kesar
bg-elaichi
bg-teal
bg-[#ff6600]
border-masala

3. Typography

text, font, leading

Smart chai-text-* disambiguates font size scales (xs..5xl), pixel sizes, alignment, and text colors.

chai-text-2xl chai-bold (24px)
chai-text-lg chai-italic chai-text-masala (18px)
chai-uppercase chai-tracking-2
chai-font-mono chai-underline chai-text-right

4. Borders & Radius

border, rounded

Border widths, styles (solid/dashed/dotted), colors, and individual corner radii (rounded-tl-16).

border-2 rounded-8
border-dashed rounded-full
rounded-tl-16 rounded-br-16
border-[2px_dotted_#8fae6b]
